## `convert_links.py`

Скрипт для преобразования Obsidian-стиля ссылок (`[[wikilinks]]`) в стандартный Markdown-синтаксис (`[links](path)`).

### Зачем это нужно
Если название файла окажется не уникаьлным, Quartz выдаст просто ошибку 404 на сайте.

### Как запустить
Скрипт следует запускать из корня репозитория. Команда для запуска:
```bash
python scripts/convert_links.py apply-all
```

### Последовательность действий скрипта
1. Сканирует папку `itmo-notebook/` на наличие `.md` файлов.
2. Ищет `[[ссылки]]` и `![[вставки]]`.
3. Пытается найти целевой файл в проекте.
4. Если имен несколько (конфликт), выбирает файл из того же раздела (OPD/MatAn).
5. Заменяет на `[текст](путь/до/файла)` без расширения `.md` для заметок.
6. Сохраняет изображения и другие вложения с их расширениями.
7. Поддерживает алиасы (`[[путь|текст]]`) и размер изображений (`![[img.png|400]]`).
8. Если целевой файл не найден, скрипт выводит предупреждение в консоль, но всё равно преобразует ссылку в Markdown-формат, используя исходный текст.
