# Скрипты для проверки и преобразования заметок

Запускай команды из корня репозитория. Правила оформления заметок описаны в [заметке «Оформление»](../FORMATTING.md), порядок работы над PR -- в [CONTRIBUTING](../CONTRIBUTING.md).

## Единая команда

`main.py` -- каноническая точка входа. Она последовательно нормализует вставки, преобразует ссылки, затем форматирует формулы. По умолчанию обрабатывается `itmo-notebook/`.

```bash
python scripts/main.py
```

Проверить без записи:

```bash
python scripts/main.py --check
```

Указать другой корень можно через `--root PATH`. Чтобы запустить один или несколько шагов, перечисли их имена; шаги всё равно выполняются в стандартном порядке:

```bash
python scripts/main.py --root /tmp/notes --check check_math convert_links
python scripts/main.py ensure_blank_after_embed
```

Доступны шаги `ensure_blank_after_embed`, `convert_links` и `check_math`. `scripts/normalize.py` поддерживается для совместимости и передаёт аргументы в `main.py`.

## Поведение шагов

- `ensure_blank_after_embed` ставит пустую строку после строки, целиком занятой вставкой `![alt](путь)` или `![[файл]]`. В цитате пустая строка получает тот же префикс `>`. Frontmatter и fenced-блоки не изменяются
- `convert_links` заменяет Obsidian-вики-ссылки на Markdown-ссылки, разрешает имена вложений по имени файла и stem, а корневые пути Markdown-ссылок переписывает относительно каталога заметки. У заметок расширение `.md` отбрасывается, у вложений сохраняется. В ITMO ссылка `[[blue_bible.pdf]]` ведёт на внешний документ
- `check_math` выносит display-разделители `$$` на отдельные строки и убирает пробелы внутри inline-формул вне code spans. Экранированные знаки доллара, таблицы, заголовки, frontmatter и fenced-блоки обрабатываются без изменения смысла

Неразрешённые и неоднозначные ссылки выводятся списком, и при исправлении не меняется ни один файл, пока все такие ссылки не будут устранены. Конвертер сохраняет корректный синтаксис destinations в угловых скобках, в том числе когда путь содержит пробелы или скобки.

## Тесты

Все Python-тесты используют временные каталоги и не читают заметки репозитория:

```bash
python -m unittest discover -s scripts/tests -t .
```

Плагин ширины картинок проверяется отдельно:

```bash
npx tsx --test quartz/plugins/transformers/imageWidth.test.ts
```

## CI

Workflow `.github/workflows/ci.yml` запускает `python scripts/main.py` перед сборкой и `python scripts/main.py --check` для PR, а также выполняет тесты и проверку EditorConfig.
