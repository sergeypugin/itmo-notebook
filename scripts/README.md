# Скрипты для проверки и преобразования заметок

Запускай команды из корня репозитория.

## Преобразование ссылок

`convert_links.py` заменяет Obsidian-вики-ссылки на стандартные Markdown-ссылки. Для заметок путь в ссылке записывается от корня хранилища без `.md`; для вложений сохраняется расширение. Если цель не найдена или неоднозначна, скрипт оставляет ссылку без изменений, печатает путь к файлу, номер строки, исходную ссылку и причину, затем завершает работу с кодом ошибки.

Команда преобразования всех определённых ссылок:

```bash
python scripts/convert_links.py apply-all
```

Проверка без изменения файлов: выводит все оставшиеся вики-ссылки, включая те, которые можно было бы преобразовать, и завершает работу с ошибкой.

```bash
python scripts/convert_links.py check
```

В выводе указаны файл, строка, ссылка и причина. Ненайденные и неоднозначные ссылки нужно исправить вручную.

## Исправление формул

`check_math.py` автоматически форматирует формулы в Markdown-файлах хранилища и ничего не выводит при успешном запуске. Он не меняет таблицы, заголовки, строки с inline code и fenced code blocks. Остальные однострочные display-формулы переносит в отдельные блоки с `$$` на собственных строках, в том числе разделяет соседние формулы, склеенные через `$$$$`. У inline-формул убирает пробелы непосредственно после открывающего и перед закрывающим `$`.

```bash
python scripts/check_math.py
```

## Автоматическая проверка в GitHub Actions

Workflow `.github/workflows/ci.yml` запускается на push и при обновлении PR: преобразует ссылки, форматирует формулы, применяет EditorConfig и коммитит исправления в текущую ветку. После push в `main` workflow дополнительно проверяет ссылки и публикует сайт.

Чтобы ошибка workflow блокировала слияние PR, добавь этот workflow как обязательную проверку в правилах защиты ветки `main`. Сам по себе GitHub Actions не запрещает слияние при проваленной проверке, если для ветки не настроено такое требование.

Для коммитов в `main` workflow использует встроенный `GITHUB_TOKEN` с правом `contents: write`. Для авто-коммитов в ветку PR из форка нужен секрет `AUTO_FORMAT_TOKEN` с правом записи в репозиторий форка; GitHub не передаёт секреты в такие PR автоматически.
