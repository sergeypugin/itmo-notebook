## Условия существования определённого интеграла

### Критерии в терминах сумм и интегралов Дарбу

### Теорема
Следующие утверждения равносильны:

1. $f \in R[a, b]$.
2. Критерий Дарбу:
$$
\lim_{\lambda(\tau) \to 0} (S_\tau(f) - s_\tau(f)) = 0.
$$
3. Критерий Римана:
$$
\forall \varepsilon > 0 \ \exists \tau: \ S_\tau(f) - s_\tau(f) < \varepsilon.
$$
4. Критерий в терминах интегралов Дарбу: $f$ ограничена и $I_*(f) = I^*(f) = \int_a^b f \ dx$.

### Доказательство

- $1 \Rightarrow 2$:
Из $|\sigma_\tau - I| < \varepsilon/3$ при мелкости $\lambda(\tau) < \delta$ переходим к супремуму и инфимуму по оснащению $\xi$. Получаем $S_\tau \le I + \varepsilon/3$ и $s_\tau \ge I - \varepsilon/3$, откуда $S_\tau - s_\tau < \varepsilon$.

- $2 \Rightarrow 3$: Очевидно.

- $3 \Rightarrow 4$:
Конечность сумм Дарбу даёт ограниченность $f$. Из $S_\tau - s_\tau < \varepsilon$ и неравенств $I_* \ge s_\tau$, $I^* \le S_\tau$ получаем $I^* - I_* < \varepsilon$, значит, $I^* = I_*$.

- $4 \Rightarrow 1$:
$s_\tau \le \sigma_\tau \le S_\tau$, и обе стремятся к $I$ при $\lambda(\tau) \to 0$. По теореме о сжатой переменной $\sigma_\tau \to I$.

### Критерии в терминах колебаний

Колебание функции $f$ на множестве $E$:
$$
\omega(f, E) = \sup_{x, y \in E} |f(x) - f(y)| = \sup_E f - \inf_E f.
$$

Теорема. Следующие утверждения равносильны:

1. $$f \in R[a, b]$$
2. $$\lim\limits_{\lambda(\tau) \to 0} \sum\limits_{i=1}^n \omega(f, \Delta_i) \Delta x_i = 0$$
3. $$\forall \varepsilon > 0 \ \exists \tau: \ \sum\limits_{i=1}^n \omega(f, \Delta_i) \Delta x_i < \varepsilon$$

>Доказательство немедленно следует из $S_\tau - s_\tau = \sum \omega(f, \Delta_i) \Delta x_i$.

## Классы интегрируемых функций

### Интегрируемость непрерывной функции

### Теорема 
$$f \in C[a, b] \ \Rightarrow \ f \in R[a, b]$$

### Доказательство

По теореме Кантора $f$ равномерно непрерывна: для $\varepsilon > 0$ найдётся $\delta$, при котором $|x_1 - x_2| < \delta$ влечёт $|f(x_1) - f(x_2)| < \varepsilon/(b-a)$. При $\lambda(\tau) < \delta$ колебание на каждом $\Delta_i$ меньше $\varepsilon/(b-a)$. Тогда $\sum \omega(f, \Delta_i)\Delta x_i < \varepsilon$, и по критерию Римана $f \in R[a, b]$.

### Интегрируемость ограниченной функции с конечным числом точек разрыва

### Теорема
Ограниченная на $[a, b]$ функция с конечным числом точек разрыва интегрируема.

### Доказательство

Вокруг каждой из $k$ точек разрыва строим интервалы малой длины (суммарно $< \varepsilon/(4C)$, где $|f| \le C$). На оставшихся отрезках $f$ непрерывна и равномерно непрерывна, что даёт колебание $< \varepsilon/(2(b-a))$. Суммируя, получаем общую сумму колебаний $< \varepsilon$, и по критерию Римана $f$ интегрируема.

### Интегрируемость монотонной функции

### Теорема
Монотонная на $[a, b]$ функция интегрируема.

### Доказательство

Пусть $f$ не убывает и не постоянна. Берём $\delta = \varepsilon/(f(b)-f(a))$ и разбиение с $\lambda(\tau) < \delta$. Тогда
$$
\sum \omega(f, \Delta_i) \Delta x_i < \delta \sum (f(x_i) - f(x_{i-1})) = \delta (f(b)-f(a)) = \varepsilon.
$$
По критерию Римана $f \in R[a, b]$.
