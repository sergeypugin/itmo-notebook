# Лекции

В течение семестра в связи с форматом лекций было решено вести конспекты в GitHub-репозитории этого сайта. Приходилось не без помощи ИИ-агентов переводить материалы лекций в заметки.

Конспект ведётся по темам: одна тема -- одна заметка, внутри сохранена нумерация разделов источника. Материалы преподавателя («изучить самостоятельно») приходят в виде PDF-ов и попадают в конспект после конвертации при помощи hammerdown и вычитки.

Главная тема лекций всего семестра: «Кратные интегралы и теория поля»

# Темы

```base
filters:
  and:
    - file.inFolder("matan/sem3")
    - file.ext == "md"
    - file.name != "index"
    - file.name != "hm__questions_pdf"
views:
  - type: table
    name: Все темы
    order:
      - file.name
      - title
    sort:
      - property: file.name
        direction: ASC
```
