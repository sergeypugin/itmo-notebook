# Лекции

В течение семестра в связи с форматом лекций было решено вести конспекты в GitHub-репозитории этого сайта. Приходилось не без помощи ИИ-агентов переводить скрины в заметки.

Конспект ведётся по темам: одна тема -- одна заметка, внутри сохранена нумерация разделов источника. Материалы преподавателя («изучить самостоятельно») приходят в виде PDF-ов и попадают в конспект после конвертации при помощи hammerdown и вычитки.

Главная тема лекций всего семестра: "Кратные интегралы и теория поля"

# Темы

```base
filters:
  and:
    - file.inFolder("matan/sem3")
    - file.ext == "md"
    - note.type == "tema"
properties:
  num:
    displayName: №
  questions:
    displayName: Вопросы
  status:
    displayName: Статус
views:
  - type: table
    name: Все темы
    order:
      - num
      - title
      - questions
      - status
    sort:
      - property: num
        direction: ASC
```
