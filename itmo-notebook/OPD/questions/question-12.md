# 12. Управление вычислительным процессом в БЭВМ. Команды ветвлений, цикл исполнения команды LOOP

**Вычислительный процесс** — это выполнение программы процессором во времени.

Задача управления вычислительным процессом, то есть требуемой последовательностью выполнения команд, решается в БЭВМ при помощи команд перехода, команды **LOOP** и команды HLT.

**Ветвления** в программах организуются с помощью команд перехода. Эти команды не изменяют содержимое аккумулятора и регистра переноса, а лишь изменяют содержимое регистра IP, загружая в него адрес, определяемый адресной частью команды.

![[Pasted image 20260623202616.png]]

Циклические программы используются в тех случаях, когда требуется многократно выполнять одну и ту же последовательность действий над изменяющимися данными. Для организации циклов обычно используют команды перехода и команду **LOOP**.

Команда **LOOP** служит для уменьшения на единицу содержимого адресуемой ячейки памяти и выбора дальнейшего пути выполнения программы в зависимости от знака полученного результата. Если результат неотрицателен, выполняется команда, следующая за LOOP. Если результат отрицателен, следующая команда пропускается, и выполняется команда через одну.

![[Pasted image 20260623202338 1.png]]

Для организации циклов также часто используется косвенная автоинкрементная адресация индексных ячеек. При обращении через такую ячейку её содержимое сначала используется как адрес операнда, а затем автоматически увеличивается на единицу, что удобно для последовательного обхода массивов.
