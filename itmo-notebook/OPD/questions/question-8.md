# 8. Операционная система Unix — основные команды, права файлов и способы их задания

Основные команды:

- pwd — вывод текущего каталога;
- ls — просмотр содержимого каталога;
- cd — переход между каталогами;
- mkdir — создание каталога;
- rmdir — удаление пустого каталога;
- touch — создание пустого файла или изменение времени его модификации;
- rm — удаление файла;
- cp — копирование файлов;
- mv — перемещение или переименование файлов;
- cat — вывод содержимого файла;
- head/tail — вывод начала/конца файла;
- wc — подсчёт строк, слов и символов;
- find — поиск файлов;
- ln — создание ссылок;

>*В UNIX существуют два типа ссылок:
>- **жёсткая ссылка** (hard link) — дополнительное имя файла, имеющее тот же inode, что и исходный файл;
>- **символическая ссылка** (symbolic link) — специальный файл, содержащий путь к другому файлу.

#### Права доступа к файлам

Для каждого файла определяются права доступа для трёх категорий пользователей:

- u (user) — владелец файла;
- g (group) — группа владельца;
- o (others) — остальные пользователи.

Для каждой категории могут быть установлены следующие права:

- r (read) — чтение файла │просмотр содержимого каталога;
- w (write) — запись в файл │создание и удаление файлов в каталоге;
- x (execute) — выполнение файла │переход в каталог и поиск файлов в нём.

Права представляются девятью битами: rwxr-xr--
Каждая тройка символов соответствует одной категории пользователей (ugo).
Также используется восьмеричная запись прав: r = 4; w = 2; x = 1
Для задания прав используется команда: chmod

**Основные способы задания прав:**

1. *Символьная форма*: chmod u+xw file
2. *Восьмеричная форма*: chmod 755 file
3. *Копирование прав одной категории другой*: chmod g=u file
