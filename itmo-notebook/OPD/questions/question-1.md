# Две формы представления информации. Способы представления дискретной информации. Системы счисления, используемые в вычислительной технике - двоичная, 8-я, 10-я, 16-я, двоично-десятичная

Две формы представления информации:

- Аналоговая (непрерывная)  
    Количество значений, которые может принимать величина, представленная в такой форме бесконечно велико, даже если величина изменяется в ограниченном диапазоне. Отсюда названия – непрерывная величина и непрерывная информация. Основное свойство таких величин – отсутствие разрывов, промежутков между значениями, которые может принимать аналоговая величина. Величина представляется в виде одного сигнала, пропорционального этой величине. Эта форма представления используется в аналоговых вычислительных машинах.

-  Дискретная (цифровая, прерывистая)  
    Такие величины принимают только определённые значения. В отличие от непрерывной величины количество значений дискретной величины всегда будет конечным. Величина представляется в виде нескольких сигналов, каждый из которых соответствует одной из цифр заданной величины. Есть несколько способов представления дискретной информации: знаковый (символьный), графический (пиксельный), сигнальный (физический), внутримашинный (ЭВМ).

**Перевод форм информации:**

Из аналогового в дискретное (Оцифровка / АЦП) — это разбиение непрерывного сигнала на отдельные кусочки.

Из дискретного в аналоговое (Декодирование / ЦАП) — это превращение набора чисел обратно в плавный сигнал.

>Прим.
>*Аналоговой формы:* Фильм на кинопленке — изобр. хранится в виде непрерывного химического слоя краски и галогенидов серебра.
>*Дискретная форма:* Цифровое фото (JPEG) — картинка разбита на сетку из пикселей (каждый пиксель — это цифровой код цвета)

#### Системы счисления

Для записи и обработки информации используются различные СС. Их появление связано с необходимостью удобно представлять числа как для компьютера, так и для человека.

Внутри ЭВМ используется двоичная СС, поскольку электронным устройствам проще различать всего два состояния: наличие сигнала (1) и отсутствие сигнала (0). Однако длинные двоичные записи неудобны для человека, поэтому применяются также восьмеричная и шестнадцатеричная СС, позволяющие компактно записывать двоичные данные.

>Термины: 
>*Бит — один двоичный разряд. 
>Байт — последовательность из 8 бит. 
>Слово — группа бит фиксированной длины, обрабатываемая ЭВМ как единое целое.

**Двоичная (2СС)**  
Использует две цифры: 0 и 1. Является основной системой представления данных в компьютере.

**(8СС)** 
Использует цифры 0–7. Каждая восьмеричная цифра соответствует трём двоичным разрядам. Ранее широко применялась в программировании, сейчас используется редко.

**(10СС)**  
Использует цифры 0–9. Наиболее удобна для человека, поэтому применяется при вводе и отображении числовой информации.

**(16СС)** 
Использует цифры 0–9 и буквы A–F. Каждая шестнадцатеричная цифра соответствует четырём двоичным разрядам. Удобна для компактной записи машинных кодов, адресов памяти, цветов RGB и других двоичных данных.

**Двоично-десятичная (BCD)** 
Каждая десятичная цифра кодируется четырьмя битами (от 0000 до 1001). Используется в устройствах, где важна работа именно с десятичными числами (калькуляторы, индикаторы, финансовые системы). Обеспечивает точное представление десятичных чисел, но требует больше памяти и усложняет арифметические операции.
