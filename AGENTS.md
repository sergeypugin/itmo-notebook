Подробнее о проекте -- в [README](README.md). Правила оформления заметок -- в [заметке](FORMATTING.md).

Ты -- агент редактора Zed на Windows. Всё содержимое `itmo-notebook/` публикуется через Quartz и поддерживает Obsidian Markdown.

Для нормализации запускай `python scripts/main.py`, для проверки без изменений -- `python scripts/main.py --check`. По умолчанию обрабатывается каталог `itmo-notebook/`. `scripts/normalize.py` оставлен только как совместимый wrapper. Ссылки пиши в markdown-форме с путём относительно самой заметки (для файлов рядом -- просто имя): вики-ссылки и корневые пути при проверке считаются неканоничными.

## МатАн

Папка семестра -- `itmo-notebook/matan/sem3/`:
- `01-{stem}.md` и далее -- темы; весь конспект живёт в них, одна тема -- один файл
- `index.md` -- интро, base-таблица тем и таблицы «вопрос - раздел»
- `hm__questions_pdf.md` -- причёсанный список вопросов к экзамену (оригинал -- `_questions.pdf`)
- `_questions.pdf` -- оригинальный список вопросов к экзамену
- `Attachments/` -- картинки, используемые темами
- `lection_photo/lection-x/` -- фото с пар (в gitignore)
- `lection_extra/original/` -- материалы преподавателя как есть (в gitignore)
- `lection_extra/hammerdowned/` -- их конвертация через `hammerdown` (в gitignore)

Доп. материалы приходят PDF-ами «Лекция x (изучить самостоятельно)»: положи файл в `lection_extra/original/` как `lection-x.pdf` и сконвертируй `hammerdown --include-gitignored -o itmo-notebook/matan/sem3/lection_extra/hammerdowned <файл>` (флаг обязателен: папка в gitignore, и без него hammerdown не увидит файл). Конверт даёт текст и структуру, формулы восстанавливай по оригиналу

При запросе оцифровать лекцию или тему:
- Источник -- фото из `lection_photo/lection-x/` или конверт из `lection_extra/hammerdowned/`. Работай только с запрошенным материалом
- Контент раскладывай по темам согласно `index.md`: раздел конспекта переносится целиком, а не копируется
- Заметка темы: YAML-свойство `title`, не дублируй название темы первым заголовком; сохраняй нумерацию заголовков из источника, например `1.1`, и начинай уровни заголовков с первого: `# 1.1`, подразделы -- `##`. Не делай заголовки длинными. Если соседние темы уже написаны, ориентируйся на их стиль и обозначения
- Списка вопросов в шапке темы нет: вопросы живут только в `index.md` (односторонняя навигация index -> тема). При создании или наполнении темы обнови её раздел в `index.md`: заголовок раздела сделай ссылкой на файл темы (достаточно имени файла), а тексты её вопросов в таблице преврати в ссылки на якоря разделов; вопрос из нескольких топиков оформляй нумерованными ссылками (`1) ... 2) ...`). Вопросы без оцифрованных разделов оставь обычным текстом -- висячих ссылок не оставляй, `--check` должен проходить
- Колкауты: тип в lowercase, у колкаута должно быть название. Теоремы и леммы -- `[!theorem]`, следствия -- `[!corollary]`, примеры -- `[!example]`, замечания -- `[!note]`, пробелы в оцифровке -- `[!caution]`. Доказательство -- свёрнутый `[!proof]- Доказательство` внутри теоремы. В матановых темах используй только эти типы (общесайтовые `tip`, `success` и прочие -- не для конспекта; рендерятся, но не входят). В названии колкаута математика допустима, а в заголовках разделов её быть не должно: она ломает якоря и оглавление. В caution допустимо краткое объяснение происхождения пробела
- В заметках нет отсылок к номерам лекций, фотографиям и доскам, а также заявлений об использовании конспектов преподавателя. Если материал восстановлен по рассказанному на лекции, пиши «восстановлено по тому, что рассказывал А. И. Попов (наш лектор) на лекции»; фамилию -- только в форме «А. И. Попов»
- Вложенные фото: ограничивай ширину через `![alt|600](путь)` только если фото само по себе маленькое и его не надо растягивать на всю страницу; большие фото оставляй как есть
- Прогони `python scripts/main.py --check`

В конце новой темы добавляй навигацию:

```markdown
---

[Предыдущая тема](0X-stem) | [Все темы](index) | [Следующая тема](0Y-stem)
```

Если соседней темы ещё нет, убери её ссылку. Обнови соседнюю тему, добавив ссылку на новую.
